> Authorized dual-domain security toolchain (web recon + code analysis)

## Usage

```bash
Usage: weeping-angel [OPTIONS] <COMMAND>
```

## Details

Authorized security toolchain: live web recon/DAST and algorithmic code scans.

Web scans require --i-own-this and --allow-host (or --allow-host-from-target).
Targets accept bare hosts (example.com), //host, http://, or https://.
Consent: --i-own-this or --i-own-this=true|yes|1 (value requires =).

Code/diff scans produce Codex Security–compatible sealed bundles.

## Arguments

| Flag / arg | Description | Default |
|---|---|---|
| `--version` | Print version (-v, -V, --version). Works without a subcommand | `—` |
| `--verbose` | Increase logging verbosity (repeatable) | `—` |

## Subcommands

- [`scan-diff`](/docs/commands/scan-diff) — Algorithmic code SAST on a Git change-set (PR/commit/working-tree)
- [`workbench`](/docs/commands/workbench) — Local SQLite workbench: register / list sealed scans
